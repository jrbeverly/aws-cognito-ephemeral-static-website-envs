# Hugo Docs Test Site

Welcome to the Hugo Docs Test Site. This example site is more complex than the
basic example — it contains multiple pages organised into sections, a navigation
sidebar, and enough nested paths to exercise the gateway path resolution.

## Sections

- **[Getting Started](/getting-started/)** — prerequisites and installation
- **[Guides](/guides/)** — configuration and deployment walkthroughs
- **[Reference](/reference/)** — glossary and reference material

## Purpose

This site is used to verify that a multi-section Hugo site builds correctly and
that all nested paths, assets, and navigation links work after publishing through
the platform.
