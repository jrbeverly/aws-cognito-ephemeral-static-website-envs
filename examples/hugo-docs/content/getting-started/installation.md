# Installation

This page covers installing the tools needed to build a Hugo site.

## Prerequisites

- Hugo extended version 0.120 or later
- A text editor
- Basic familiarity with the command line

## Install Hugo

On macOS with Homebrew:

```sh
brew install hugo
```

On Linux:

```sh
sudo apt install hugo
```

Or download a prebuilt binary from the [Hugo releases page](https://github.com/gohugoio/hugo/releases).

## Verify the installation

```sh
hugo version
```

You should see the Hugo version and build information.
