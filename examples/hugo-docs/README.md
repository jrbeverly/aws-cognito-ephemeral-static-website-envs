# Hugo Docs-Style Example

A more complex Hugo site for testing nested paths and multi-page publishing.

## Contents

- Multiple pages
- Navigation
- CSS or generated assets
- Enough structure to exercise nested path resolution

## Build

```sh
cd examples/hugo-docs
hugo
```

The `public/` output directory should be zipped and uploaded through the portal.

See `VISION.md` §10.2 for example site requirements.
