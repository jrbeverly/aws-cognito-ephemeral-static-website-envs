# Hugo Basic Example

A minimal Hugo site for testing the zip upload and publish flow.

## Contents

- A homepage
- At least one additional page
- At least one static asset
- A clear title indicating it is a test site

## Build

```sh
cd examples/hugo-basic
hugo
```

The `public/` output directory should be zipped and uploaded through the portal.

See `VISION.md` §10.1 for example site requirements.
